=== AI Data Engine 1.3

AI Data Engine은 NetApp Console을 통해 관리되는 메타데이터 인텔리전스 서비스로, 연결된 시스템을 스캔하고 메타데이터 카탈로그를 구축하며, 스토리지를 최적화하고 대규모로 데이터를 관리할 수 있는 가시성과 툴을 제공합니다. AI Data Engine을  https://docs.netapp.com/us-en/ai-data-engine/deploy/deployment-overview.html["AIDE 단일 노드 배포"^](으)로 배포하거나, 환경에서 대규모의 Kubernetes 기반 고가용성이 필요한 경우 AIDE 다중 노드 배포로 배포할 수 있습니다.

AI Data Engine 1.3은 최초의 일반 출시(GA) 버전입니다.

.데이터를 배포하고 연결하세요
https://docs.netapp.com/us-en/ai-data-engine/deploy/deployment-overview.html["환경에 필요한 규모로 배포하세요"^]:: 단일 VM에서 빠른 시작을 위해 AIDE 단일 노드 배포를 선택하거나, 고가용성 및 대규모 확장을 위해 자체 Kubernetes 클러스터에서 AIDE 다중 노드 배포를 선택하십시오. 환경에서 인터넷에 연결하기 위해 프록시가 필요한 경우, https://docs.netapp.com/us-en/ai-data-engine/deploy/configure-proxy.html["AIDE용 프록시에 대해 알아보기"^] 프록시를 사용하여 배포하십시오.
https://docs.netapp.com/us-en/ai-data-engine/data-sources/connect-data-source.html["데이터를 범위에 포함하십시오"^]:: 파일 공유, 데이터베이스 서버 및 StorageGRID 시스템을 연결하고 스캔할 데이터 리소스를 선택하십시오.
https://docs.netapp.com/us-en/ai-data-engine/administer/monitor-deployment-health.html["스캔을 정상 상태로 유지하십시오"^]:: 배포 상태를 모니터링하여 스캔을 방해할 수 있는 문제를 파악하고, 문제를 해결하는 데 필요한 세부 정보를 수집하십시오.


.스토리지를 최적화하고 데이터를 조사하십시오
https://docs.netapp.com/us-en/ai-data-engine/investigate/understand-dashboard.html["스토리지 용량 복구"^]:: 설정된 임계값을 기준으로 연결된 시스템 전체에서 콜드, 오래된, 중복 데이터를 식별하고, 어떤 시스템과 데이터 소유자가 이러한 데이터를 가장 많이 보유하고 있는지 확인하십시오.
https://docs.netapp.com/us-en/ai-data-engine/administer/configure-settings.html["조직의 콜드 및 비활성 데이터를 정의하십시오."^]:: 보존 정책에 맞춰 어떤 데이터를 콜드 또는 비활성 데이터로 분류할지 결정하는 임계값을 설정하십시오.
https://docs.netapp.com/us-en/ai-data-engine/investigate/understand-dashboard.html["데이터 관련 문의 담당자를 확인하세요"^]:: 대시보드에서 어떤 데이터 소유자가 콜드, 비활성 또는 중복 데이터를 가장 많이 보유하고 있는지 확인하십시오. 그런 다음 조사 보기에서 소유자 또는 그룹별로 필터링하여 결과를 검토하고 연락할 담당자를 찾으십시오.
https://docs.netapp.com/us-en/ai-data-engine/investigate/investigate-data.html["비용 및 위험 감소"^]:: 연결된 모든 시스템에서 액세스 시간, 수정 날짜, 생성 날짜, 파일 크기, 중복 여부 및 기타 기준에 따라 필터링하여 조직의 데이터 관리 목표에 부합하는 파일을 찾으십시오. 검색 결과를 바로 활용하거나 기준을 정책으로 저장할 수 있습니다.
https://docs.netapp.com/us-en/ai-data-engine/investigate/investigate-data.html["중복 데이터 제거"^]:: 연결된 시스템 전체에서 중복된 파일을 찾습니다. 중복 속성 또는 파일 해시를 기준으로 필터링하여 중복 그룹을 검토한 다음 중복된 파일을 정리합니다.
https://docs.netapp.com/us-en/ai-data-engine/investigate/investigate-directories.html["액세스 위험 찾기"^]:: 권한이 열려 있는 디렉터리를 식별하여 권한 검토의 우선순위를 정하십시오.
https://docs.netapp.com/us-en/ai-data-engine/investigate/investigate-structured.html["정형 데이터 조사"^]:: 연결된 데이터베이스 서버 전체에서 크기가 너무 크거나 사용되지 않는 데이터베이스 테이블을 찾으십시오.


.데이터를 기반으로 조치를 취하고 시간 경과에 따라 모니터링하십시오
https://docs.netapp.com/us-en/ai-data-engine/investigate/take-actions.html["스토리지 비용 절감"^]:: 파일을 NFS 또는 SMB 대상으로 복사 및 보관하거나, 추적을 위해 항목에 태그를 지정하거나, 보존 요구 사항에 따라 파일을 영구적으로 삭제하여 조직의 데이터 라이프사이클 정책을 시행하십시오.
https://docs.netapp.com/us-en/ai-data-engine/policies/create-policy.html["데이터 상태를 지속적으로 모니터링합니다"^]:: 콜드 파일 또는 크기가 큰 파일 등 반복되는 데이터 조건을 시간이 지남에 따라 추적하기 위해 필터 기준을 명명된 정책으로 저장하고, 영향을 받는 파일 수가 변경될 때 알림을 받으십시오.


.AI 접근 제어
https://docs.netapp.com/us-en/ai-data-engine/mcp/learn-about-mcp.html["AI 클라이언트에게 메타데이터에 대한 통제된 액세스 권한을 부여하십시오."^]:: 모델 컨텍스트 프로토콜(MCP)을 통해 Claude Code, Claude Desktop, Cursor 또는 OpenCode를 AI Data Engine에 연결합니다. AI 클라이언트가 검색할 수 있는 컬렉션을 활성화하고 Microsoft Entra ID 범위를 사용하여 각 컬렉션을 검색할 수 있는 사용자를 제어합니다. AI 클라이언트는 메타데이터와 태그 파일을 검색할 수 있습니다.


.관리
https://docs.netapp.com/us-en/ai-data-engine/administer/manage-users-roles.html["관리자 및 뷰어 역할 할당"^]:: 조직 내 사용자에게 AI Data Engine 관리자 또는 뷰어 역할을 할당하여 데이터를 조사하고 조치를 취할 수 있는 사용자를 제어할 수 있습니다.
