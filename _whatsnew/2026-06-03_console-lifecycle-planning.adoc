=== 라이프사이클 계획 기능 이름 업데이트

다음과 같은 Lifecycle 계획 기능의 이름이 변경되었습니다.

* 기술 업데이트 기능이 이제 *시스템 새로 고침*으로 이름이 변경되었습니다. 방법을 알아보세요 https://docs.netapp.com/us-en/console-lifecycle-planning/use/tech-refresh.html["시스템 새로 고침 평가"].
* 용량 추가 기능이 이제 *Storage Expansion*으로 이름이 변경되었습니다. 방법을 알아보세요 https://docs.netapp.com/us-en/console-lifecycle-planning/use/capacity-add.html["스토리지 확장"].
* 갱신 기능이 이제 *Support Renewals*로 이름이 변경되었습니다. 방법을 알아보세요 https://docs.netapp.com/us-en/console-lifecycle-planning/support/task-support-registration.html["지원 등록"].
